# Roadmap Ecommerce Foundation

Este repositorio forma parte del roadmap personal de Ingenieria informática orientada al mercado remoto internacional

## Objetivo

Contruir una base profesional de desarrollo usando GitHub Codespace, Node.js, Git, Rust, MySQL, Dev Containers. 

## Stack inicial

- GitHub Codespaces
- Ubuntu 22.04
- Dev Containers
- Git
- Node.js 20
- Rust stable
- MySQL 8.4
- Docker Compose
